## 1. 방법 (GazePrune) 최종 설정

- **ranker:** layer 2 입력에서 visual 토큰 순위를 매기는 작은 MLP예요.
  - 입력: layer-1 visual hidden(PCA **256**), 액션 쿼리 평균 hidden, 패치 위치
  - **avis(layer 0–1 attention)는 쓰지 않아요.** ablation에서 기여가 0이었어요.
  - **two-head:** 액션 head와 지시문 head가 있고, 추론 때 $p=(1-w)\,\mathrm{softmax}(z^{act})+w\,\mathrm{softmax}(z^{instr})$ 로 섞어요. **$w=0.35$**
- **학습:** 예산과 무관하게 순위만 배워요(KL). 체크포인트는 검증 KL로 골라요.
- **스케줄:** 학습 라벨을 비율 $w$ 로 섞고, 그 위에서 DP를 풀어 층별 토큰 수 $n_l$ 을 만들어요(`make_schedule.py --mix w`).
  - OFT: 20% (b3280 = 32×512 중 3280)
  - base OpenVLA: 30% (b2450)
- **라벨 쿼리 위치 (OFT):** 공식 액션 head가 읽는 위치 $[T-58, T-2)$ 예요.
- **추론 (OFT):** `official.py`에서 순위대로 한 번 재배치한 뒤, 층마다 앞부분만 잘라 써요. GPU 동기화가 없어요.
- **수식 문서:** `plan/OFT_labels_features.md`, `plan/OFT_benchmark_measurement.md`

## 6. 다음 단계: π0 (pi0)를 LIBERO에서 같은 방식으로

목표는 OFT와 같은 파이프라인이에요. π0 LIBERO 체크포인트를 받고 → 라벨 → ranker 학습 → 스케줄 → 500ep 평가 → Full과 베이스라인 비교까지 가요. **아직 아무것도 시작하지 않았어요.** 아래 사양 중 "확인 필요"는 직접 검증해야 해요.

1. **모델과 체크포인트 (확인 필요)**
   - Physical Intelligence의 openpi 저장소에 LIBERO로 파인튜닝한 π0 설정(`pi0_libero`)과 체크포인트가 공개돼 있는 것으로 알고 있어요. 기본은 JAX이고, PyTorch 버전이나 LeRobot 버전이 있는지는 확인이 필요해요.
   - 우리 파이프라인(PyTorch forward hook)과 맞추려면 PyTorch 구현이 편해요.
   - 구조: PaliGemma(SigLIP + Gemma 2B, hidden 2048, 18층) + action expert(약 300M). 액션은 flow matching으로 약 10번 반복해서 만들어요.
   - LIBERO 입력: 3인칭 + 손목 카메라라 visual 토큰은 256 × 2 = 512개로 보여요. 세 번째 이미지 슬롯은 마스킹돼요. 확인 필요해요.
   - LIBERO 성공률을 Full로 먼저 재현한 뒤 진행해야 해요.
2. **OFT와 다른 점**
   - **액션 쿼리:** 액션 토큰이 LLM이 아니라 action expert 안에 있어요. 라벨은 action expert의 액션 토큰이 prefix(이미지 + 지시문) KV를 보는 attention으로 정의해요.
   - **denoising step:** step마다 attention이 달라요. 기본은 step 평균으로 라벨 하나를 만드는 거예요.
   - **프루닝 위치:** prefix(PaliGemma) forward는 쿼리마다 한 번이고, action expert가 그 KV를 반복해서 읽어요. 그래서 visual 토큰을 줄이면 prefix 계산과 10번 반복되는 cross 부분이 함께 줄어요. FLOPs 공식도 이 구조에 맞춰 새로 써야 해요.
   - **예측기 위치:** OFT처럼 prefix layer 2 입력에서 순위를 매기고, 그 뒤 층별로 토큰 수를 줄여요. 층 수가 18이라 스케줄 길이도 18이에요.
3. **라벨 용량 (PCA 256, avis 없음 기준 추정)**
   - 프레임당 약 0.29 MB예요. LIBERO 4 suite는 273,465프레임(spatial 52,970 / object 66,984 / goal 52,042 / libero_10 101,469)이라 **약 78 GB**예요.
   - PCA 512면 약 145 GB이고, 라벨을 denoising step별로 저장하면 약 +90 GB예요.
   - 지금 디스크 여유는 약 200 GB예요.
4. **재사용할 코드**
   - `gazeprune/ranker.py`(DepthRanker, two-head, drop, pca_dim), `schedule.py`(DP, make_schedule), `predictor.py`, `train/train_ranker.py`는 차원(M, hidden dim, 층 수)만 맞추면 그대로 써요.
   - 새로 만들 것:
     - π0용 depth forward (`gazeprune/oft.py`에 해당)
     - 라벨러 (`teacher/label_oft.py`에 해당)
     - 평가 진입점과 profiler hook (Gemma와 action expert 둘 다)
5. **비교 대상**
   - Full π0, 그리고 π0을 지원하는 베이스라인이에요. SpecPrune, VLA-Pruner, SAFE-Pruner는 OFT나 OpenVLA 전용이라 직접 이식해야 해요.
   - 같은 FLOPs에서 비교하도록 예산을 맞춰요.
